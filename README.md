# Projeto Integrador — 1º Semestre

Projeto integrador acadêmico desenvolvido para praticar desenvolvimento web e organização de uma aplicação com múltiplas páginas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Conteúdo

O projeto possui páginas como início, configuração, ajuda e conteúdo popular, organizadas em arquivos HTML e recursos de front-end.

## Como executar

Abra `index.html` no navegador ou utilize o Live Server.

## Status

Projeto acadêmico.
